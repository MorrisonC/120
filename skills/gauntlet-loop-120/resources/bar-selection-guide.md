# Bar Selection Guide — 120

Same three checks as the source pattern
(https://github.com/robonuggets/gauntlet-loop): **Named**, **Fetchable**,
**Comparable**.

## The obvious starting bar: Minit itself

You've described this project's identity in terms of Minit (Devolver
Digital) — that makes it a strong Named/Comparable starting point for
several targets, PROVIDED it's actually Fetchable: real gameplay footage
or screenshots you can point the critic at (a specific let's-play
timestamp, or official press screenshots), not just "Minit" as a
remembered concept. Confirm you can fetch something concrete before
locking it in — same rule as every other project in this family.

## Per-target guidance

**ProceduralVarietyFeel** — Minit's own biome variety is a fair
comparison since it's the explicit tone reference, but Minit is NOT
procedurally generated (it's hand-authored) — so the bar here should
really be about whether consecutive *captured seeds* of 120 read as
distinct from each other, judged against Minit's hand-authored variety
as a quality floor, not a 1:1 mechanic comparison. Say this distinction
in the bar proposal so the critic isn't confused about what's actually
comparable.

**ArtThemeConsistency** — same Minit tone reference works well here
directly, since this is about visual/style coherence, which Minit
demonstrates clearly across its whole handmade world.

**DifficultyPacingFeel** — per `COMPLEXITY_GRAPH.md` Section 3, most of
this should resolve via the numeric critical-path analysis BEFORE it
reaches a critic at all. Only bring genuinely ambiguous seeds here.
Minit's own tension pacing (does a 120-second run feel appropriately
tight without feeling impossible) is the natural bar for the remaining
ambiguous cases.

**NPCDialogueQuality** — Minit doesn't have much NPC dialogue depth to
compare against (deliberately minimal, single-button-press interactions)
— don't force this comparison. Pick a different named fantasy game
with dialogue you can actually point to text/screenshots of. Keep the
comparison scoped to "reads as fantasy-appropriate and voiced
consistently," not "as sparse as Minit," since sparse-by-design in Minit
isn't the same bar as this project's stated NPC/dialogue ambitions.

**HintSystemClarity** — pick a named game specifically well-regarded for
nudge-not-solve hinting (this is a distinct, well-known design
challenge in the puzzle genre — look for one with documented/discussed
hint design, not just any puzzle game).

## Proposal format
Same as the rest of the family:
```
Target: ArtThemeConsistency

1. Minit (Devolver Digital) — [link to specific footage/screenshots]
   Why: explicit tone reference already named for this project; strong
   example of visual coherence across hand-authored variety.
```
Wait for a pick. Write only the picked bar into `state/<target>.yaml`.
